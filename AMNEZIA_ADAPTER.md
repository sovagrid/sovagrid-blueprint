# Адаптер Amnezia: границы мониторинга и управления

SovaGrid читает состояние существующих Amnezia-контейнеров отдельно от собственного WireGuard. Обычный `run.sh` не принимает контейнеры Amnezia под управление и не включает запись в их конфигурацию. Установка, принятие контейнера и разрешение root-брокера выполняются отдельно администратором на **своём** Ubuntu-хосте через Connect или root-only инструменты. Подробный контракт и команды: [sovagrid-vpn/AMNEZIA_ADMIN.md](../sovagrid-vpn/AMNEZIA_ADMIN.md).

## Мониторинг

Root-процесс проверяет только известные имена контейнеров, закреплённый образ, состояние процесса, интерфейса, конфигурации и реестра клиентов. В очищенный `amnezia_details` попадают состояние, число настроенных и работающих клиентов, агрегированный трафик и время последнего handshake. Ключи, PSK, UUID, адреса клиентов, endpoint и сырой вывод Docker/`wg show dump` в Hub не передаются. Ошибка одного probe не скрывает состояние других источников VPN.

Состояние Docker `Up` само по себе не доказывает, что VPN-интерфейс работает. При чужом образе либо расхождении конфигурации и runtime адаптер помечает источник недостоверным и не выполняет управляющих команд.

## Опциональное управление AWG2 и WireGuard

Отдельный root-owned Unix-брокер разрешает только структурированные `status`, `settings-preview`, `add-profile`, `sealed-export` и `revoke` для AWG2 или стандартного WireGuard. `enroll` и `recover` остаются root-only операциями и не доступны обычным заданиям Agent. Hub проверяет роль администратора, выбранный сервер и форму запроса; Agent сверяет точную команду, а брокер повторно проверяет локальное разрешение, PID Agent, контейнер, образ, файлы и runtime. Hub и Agent не получают Docker socket.

Добавлять и отзывать можно только клиентов, созданных SovaGrid. Перед записью брокер создаёт закрытый журнал исходных файлов, сверяет хеши, выполняет изменение и проверяет конфигурацию и работающий интерфейс. При подтверждённом сбое он восстанавливает прежнее состояние. При потере ответа результат считается неопределённым: администратор сначала проверяет свежий статус и журнал, затем решает, нужен ли повтор.

Клиентский `.conf` выдаётся в зашифрованном конверте: браузер или приложение создаёт временную пару P-256, а профиль расшифровывается только на устройстве. Закрытый профиль не сохраняется в Hub и не попадает в аудит. Совместимость с конкретной версией официального клиента и последующим управлением через AmneziaVPN проверяйте на отдельном стенде перед включением управления рабочим контейнером.

## Числовые параметры AWG3

`settings-plan` только рассчитывает изменение разрешённых числовых полей. `settings-intent` создаёт короткоживущее одноразовое подтверждение; `settings-apply` применяет ровно этот план после повторной проверки хешей и поколения. Применение возможно только при нуле клиентов, подтверждённых runtime-селекторах и отдельном root-owned разрешении. Порт и ключи сервера этим действием не меняются. При наличии клиентов план остаётся только для просмотра: для изменения понадобится отдельная миграция и перевыдача профилей.

Старое приложение AmneziaVPN и SovaGrid не разделяют общий lock. Если они одновременно изменят один конфиг, SovaGrid откажется при обнаружении drift; полностью исключить гонку без единого протокола записи невозможно. Для любой записи администратор должен обеспечить короткое окно без параллельных изменений.

## Изолированная проверка

Тестовые AWG2/WireGuard-контейнеры запускайте без производственных томов, ключей, опубликованных портов и сети, если сеть не нужна для конкретного теста. Проверяйте добавление и отзыв только синтетического клиента, сохранность старых peer, откат на каждом шаге записи, смену container/image ID, внешний drift и восстановление после обрыва. Для проверки handshake используйте отдельную одноразовую VM или внутреннюю тестовую сеть. Сценарии находятся в `sovagrid-vpn/lab/`; результаты стенда не означают, что произвольная живая установка автоматически безопасна для записи.

Xray остаётся только для чтения. Изменение серверных настроек, требующее рестарта контейнера или перевыдачи профилей, относится к отдельному мастеру миграции.
