# Удаление управляемого Hub

Запустите `run.sh` из проверенного серверного архива на самом Hub. Сначала посмотрите план:

```bash
sudo bash sovagrid-blueprint/run.sh --uninstall --plan
```

План показывает службы, каталоги и Agent, установленные через этот Hub. Для каждого Agent нужен SSH-профиль из `~/.ssh/config` с уже проверенными ключами узлов. В профиле можно указать `ProxyJump` с несколькими переходами. На конечном сервере требуется root либо SSH-пользователь с `sudo -n` для установщика. При запуске от обычного пользователя с `sudo` используется его конфигурация OpenSSH.

```bash
sudo bash sovagrid-blueprint/run.sh --uninstall
```

При удалении скрипт запрашивает SSH-профили, проверяет принадлежность каждого Agent и показывает итоговый список. Для автоматического выбора уже настроенных профилей передайте `--route SERVER_ID=SSH_PROFILE` для каждого сервера. Удаление начинается после ввода `REMOVE SOVAGRID` в терминале.

Hub удаляется после того, как все Agent подтвердят удаление. При обрыве связи Hub остаётся на месте и позволяет повторить операцию. Уже удалённые Agent подтверждают результат по локальной квитанции. Незавершённые установки сначала нужно завершить или отменить в панели. Если происхождение Agent, состояние SSH или файлы установки не удаётся подтвердить, скрипт останавливается до удаления Hub.

Резервные копии переносятся в отдельный каталог рядом с `/var/lib/sovagrid`; скрипт выводит точный путь. Пользовательские рабочие файлы, выгрузки и существующая конфигурация WireGuard сохраняются. Независимые SSH-службы, обратные туннели и чужие контейнеры остаются в работе.

Поддерживается полная управляемая серверная установка и Agent с базовой установкой из мастера. Развёртывания Hub-only, Agent с отдельными политиками терминала или файлов и неподтверждённые сторонние установки требуют отдельного удаления. При их обнаружении пакет отказывает до удаления Hub.
