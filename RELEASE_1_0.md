# Подготовка SovaGrid 1.0.0

Цель — единый рабочий выпуск сервера и клиентов. Текущий опубликованный серверный выпуск — `server-v0.14.1`; изменения в основной ветке ещё не означают готовность `1.0.0`. Публикация в App Store и Google Play не требуется: Android распространяется APK, Connect — сборками для компьютеров, Apple — проектом для установки через Xcode и сборкой для macOS. Для своего iPhone можно настроить подпись собственным Apple ID в Xcode.

## Пользовательские сценарии выпуска

| Сценарий | Условие готовности |
| --- | --- |
| Первый сервер | Одна команда или SSH из приложения устанавливает зависимости, Hub, Web и Agent; терминал, файлы и мониторинг контейнеров доступны после проверки. IPv4 или домен панели объяснён до ввода, путь настраивается, корень сайта сохраняется. |
| Подключение | Пароль, импортированный или созданный клиентом SSH-ключ; проверка ключа сервера; прямой маршрут и один промежуточный SSH-хост. Публичный ключ можно скопировать до подключения. |
| Дополнительные серверы | Веб-мастер и Connect устанавливают Agent на другой Ubuntu с подтверждением плана; прерванная операция восстанавливается по прежнему ID. |
| Панель на телефоне | Терминал, команды, файлы, мониторинг и настройки доступны через панель; встроенные браузеры Apple и Android поддерживают выбор файла и сохранение скачивания. Светлая/тёмная тема следует устройству или выбору пользователя. |
| Права и Telegram | Локальные аккаунты и права на серверы, ограниченные действия, аудит; токен бота вводится через UI, команды бота проверяют роль и подтверждение. |
| VPN | WireGuard и поддерживаемый AmneziaWG на локальном и удалённом Ubuntu; прямой маршрут и промежуточный SSH-хост, управление клиентами и защищённое скачивание профиля. Обновление VPN-кода сохраняет конфигурацию и клиентов. |
| Обновление | Подписанная лента с явным включением; занятый сервер откладывает замену, ошибочный выпуск откатывается, незавершённая операция восстанавливается. Подписанный переход проверяется на одноразовой Ubuntu. |
| Резервная копия | Пять согласованных файлов скачиваются через UI; чистый хост восстанавливает проверенную копию с образами, учётными записями, правами и службами. Ошибка и прерывание каждой фазы проходят проверку отката. |
| Поставка | Все клиенты закрепляют один проверенный серверный архив и его манифест; отображаемые версии, контрольные суммы и проверочные команды согласованы. Публичные материалы содержат только общие инструкции и тестовые адреса. |

## Текущий пакет работ

- Общая ранняя блокировка первой установки, обычного `run.sh`, обновления и восстановления; передача удерживаемого FD вложенному установщику. Установка зависимостей восстановления дополнительно готовит WireGuard, шифрование профилей и nftables без создания SovaGrid-служб.
- Единые возможности первой установки из Apple, Android и однокомандного bootstrap. Проверка мобильной установки учитывает доступность функций, а не только работающий Hub.
- Передача файлов встроенными WebView Apple/Android с системным выбором и сохранением, закрытыми временными файлами и ограниченной памятью.
- Подключение и включение существующего VPN-брокера через промежуточный SSH-хост; отдельная транзакция обслуживания исходников при установленном брокере.
- Полное переносимое восстановление: долговечный журнал, удерживаемые входные файлы, учётные записи, образы Docker, публикация файлов, службы и восстановление после прерывания. Пока производственное применение остаётся выключенным.

## Итоговая проверка и публикация

Сначала завершаются согласованные контракты и локальные проверки. Затем один собранный пакет проходит необходимые интеграционные сценарии на одноразовой Ubuntu, сборку Android и Apple, проверку интерфейсов на эмуляторах и формирование сборок Connect. Рутинные промежуточные коммиты не запускают CI. Номер `1.0.0` и подписанная лента публикуются после завершения этих сценариев; отдельные изменения не выпускаются отдельными релизами.

Оставшиеся подробности и дальнейшие направления перечислены в [ROADMAP.md](ROADMAP.md). Этот файл фиксирует критерии выпуска, а не утверждает, что незавершённые сценарии уже доступны пользователям.
