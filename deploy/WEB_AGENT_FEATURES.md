# Функции отдельно подключённого Agent в Web

Администратор может изменить разрешения Agent после подключения сервера:
выполнение команд, терминал и файловый менеджер. Для терминала и файлов
нужно отдельно разрешить команды. Мастер показывает текущие настройки
Ubuntu и разрешение в Hub, затем запрашивает отдельное подтверждение плана.
Установка VPN-брокера сама эти разрешения не включает.

Мастер предназначен для Agent, установленного отдельным SSH-мастером.
Потребуются SSH-данные этого сервера и root либо готовый `sudo -n`.
Поддерживаются прямой маршрут и один промежуточный SSH-хост с проверкой
обоих ключей. Установленные токен Agent и служебный туннель сохраняются.
Отключение файлов и терминала сохраняет пользовательские данные.

`POST /api/v1/browser-ssh/agent-features/preview` принимает стандартный
SSH-маршрут, `server_id` и `features: null` для чтения текущего состояния.
Для плана `features` содержит ровно три булевых поля: `commands`,
`terminal`, `files`. Ответ плана содержит непрозрачный `review_sha256`.
`POST /api/v1/browser-ssh/agent-features/apply` принимает тот же маршрут,
сервер и функции, `expected_review_sha256` и `confirm: true`.

План связывает проверенную SSH-цель, активную регистрацию, исходники,
локальное состояние и версию политики Hub. Перед применением всё
проверяется заново. Hub временно закрывает управление, проверенный
`agent_features.py` меняет настройки и службы. При закрытом управлении
Hub дожидается нового измерения Agent, повторно проверяет настройки
и очищает временный пакет. Только затем последняя проверка прав и CAS
выставляют разрешение Hub, равное выбранному `commands`. Ошибка измерения,
проверки или очистки не открывает управление.

SSH-секреты и заимствованная браузерная сессия существуют только в памяти
запроса. Закрытый `agent-features-stage.json` хранит только описание
собственного временного пакета для очистки после обрыва. На Agent
используется существующий долговечный журнал функций. При неопределённом
результате нужно снова ввести SSH-данные и проверить состояние; потерянный
ответ не считается успешным применением. Незавершённое изменение
восстанавливается тем же желаемым набором функций после нового плана.
